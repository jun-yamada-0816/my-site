間口と奥座敷

間口は、まだ知らない人に届くための動画です。ニッチに寄せすぎず、もっと多くの人が「これは分かる」と思える切り口にします。
奥座敷は、すでに見てくれている人を深いところへ連れていく動画です。 登録・相談ページ・長い話は、こちら側にあります。
間口ばかりだと通り過ぎられ、奥座敷ばかりだと新しい人が来ません。

次の1本を、AIとつくる

ClaudeCodex共通プロンプト

あなたの想いと動画の数字から、次の1本の制作指示をまとめます。 同じプロンプトを、Claude にも Codex にもそのまま貼り付けられます。

  1. 01数字と土台をまとめる
  2. 02プロンプトをコピー
  3. 03使いたいAIに渡す

生成するたびに、題材・切り口・最初の一言の型・展開・締め・撮り方・写るものを、まだ使っていない組み合わせ（型）に変えます。 題材は20のテーマに160個、切り口8・一言の型12・展開8・締め6・撮り方15・写るもの4。同じ題材や同じ物のくり返しにはしません。 型は型番（例：T011-A3-N2-S1）で記録するので、本数がたまると、どの題材・どの型が伸びたかを下の「何が効いているか」で項目ごとに比べられます。

映像は、実写に見える素材から作ります。ChatGPT（Images 2.6）に、実写の写真のようなアニメーションGIF 2つ（冒頭と最後）と写真2枚を作ってもらい、 受け取ったAI（Claude・Codex）が、カメラで撮った映像に見えるように動かして、文字と音をつけます。 受け取るファイルは音入りの mp4 1本だけ。ほかに返ってくるのは、投稿に使う題名・説明文と、登録用の1行（文字だけ）です。 ChatGPTが使えない日は、「コードだけで描く（イラスト）」を選ぶと、これまでの画風21種で作れます。 生成履歴はこのブラウザーに保存し、別の端末では登録済みの動画を参考にします。

今回は、実写の素材で作る回です。次の順に進めてください。
  1. このプロンプトを Claude（または Codex）に貼る。最初に、ChatGPT に渡す素材の指示文だけが返ってきます。
  2. その指示文を ChatGPT に貼り、できた素材4つ（GIF 2つ・写真2枚）をダウンロードする。一度に出てこないときは「続き」と送る。
  3. 素材を Claude の同じ会話に添付して送る。音入りの mp4 が届きます。
  4. 返ってきた「記録用の1行」を、「動画」タブの「記録用の1行から入力する」に貼って登録する。

この動画は として数えます。 できあがったら「動画」タブで同じ識別子で登録してください。 そろえておかないと、説明文のリンクから来た人がどの動画のぶんか分からなくなります。

今回の検証設計

題材・切り口・一言の型・展開・締め・撮り方・写るものを、毎回ちがう組み合わせにします。まだ使った回数の少ないものから選ぶので、本数が増えるほど、項目ごとに同じ本数で比べられます。 手応えのある撮り方・画風を再検証する回だけ、変更を1つに絞ります。 上の指示文にも、この設計がそのまま入ります。

次に作る動画

保存した記録から、今回の型と計測の進め方を提案します。効果や原因を断定するものではありません。

何が効いているか

動画ごとの再生数を、チャンネルの中央値で割った「倍率」で比べています。1.0倍がふつうです。 型番を記録した回は、テーマ・場面・切り口・展開・締め・撮り方・写るものでも比べます（1つの項目に3本たまるまでは「参考」）。

登録につながった動画

1000回再生あたり何人が登録したか。再生数が多い動画とは限りません。

サイトまで連れてきた力

1000回再生あたり何人がホームページに来たか。

伸びているチャンネルがしていること

星の海の場合の考え方

このチャンネルが届けたい相手は、いま眠れずにスマホを見ている人です。 そういう人は、明るく元気な動画を最後まで見ません。 最初の1秒に必要なのは、驚きではなく「これは自分のことだ」という手ざわりです。

ですので、伸ばし方も少しだけ普通と違います。 派手な効果音や煽りは合いません。かわりに効くのは、 静けさ・間・具体的な場面です。 「不安なとき」より「23時、天井を見ているとき」のほうが届きます。

そして、登録してもらうために必要なのは「登録してね」ではなく 次に何が来るか分かる約束です。 「毎晩、眠れない人へ1本」のように決まっていると、登録は約束の受け取りになります。

焦らなくて大丈夫です。1日1本を4週間続けたころに、やっと形が見えてきます。 伸びない日が続いても、それはあなたの言葉が届いていないという意味ではありません。

くわしい説明

視聴を継続（%）は、Studio の「視聴を継続」の割合です（フィードに出たうち、スワイプせずに見た人）。 「スワイプして次へ」は100%からこの値を引いて表示します。冒頭の反応を示す参考で、特定の1秒・3秒や離脱の原因は断定できません。投稿24時間後と4日後に、同じ集計範囲の数字を書き写してください。自動取得には未対応です。

日付が変わると入力欄はその日の記録になります。過去の数字は「前回」に表示され、分析にも残ります。 タイトルが同じ動画は、サムネイル・投稿日時・動画IDで見分けてください。 「Studio でこの動画の数字を見る」を押すと、その動画の画面がそのまま開きます。

取り込みの設定（YouTube APIキー）

キーを入れると、再生数だけでなくいいね・コメント数・尺・公開日時・登録者数まで自動で入ります。 入れないときは、チャンネルのページを読んで再生数と登録者数だけを取り込みます。 いいねとコメントは、そのときだけ手入力のままです。

取り方：Google Cloud コンソール でプロジェクトを作り、 「YouTube Data API v3」を有効にして、認証情報からAPIキーを作ります。課金の登録は要りません。 できたキーには「YouTube Data API v3 だけ」の制限を付けておくと安心です。
