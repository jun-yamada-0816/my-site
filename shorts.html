間口と奥座敷

間口は、まだ知らない人に届くための動画です。ニッチに寄せすぎず、もっと多くの人が「これは分かる」と思える切り口にします。
奥座敷は、すでに見てくれている人を深いところへ連れていく動画です。 登録・相談ページ・長い話は、こちら側にあります。
間口ばかりだと通り過ぎられ、奥座敷ばかりだと新しい人が来ません。

ここに書いたことはこの端末の中だけに残ります。 数字とちがって、他の人に見せるものではないからです。

形式を変えてから

伸びているチャンネルがしていること

再生数はおまけです。ショート動画がおすすめに乗るかどうかは、 最後まで見てもらえたかと もう一度見たくなったかでほぼ決まります。 登録者は、そのうえで「次も見たい」と思われた分だけ増えます。

動画を作るときの型

できているものには印が付きます。数字が足りないものは灰色のままです。

星の海の場合の考え方

このチャンネルが届けたい相手は、いま眠れずにスマホを見ている人です。 そういう人は、明るく元気な動画を最後まで見ません。 最初の1秒に必要なのは、驚きではなく「これは自分のことだ」という手ざわりです。

ですので、伸ばし方も少しだけ普通と違います。 派手な効果音や煽りは合いません。かわりに効くのは、 静けさ・間・具体的な場面です。 「不安なとき」より「23時、天井を見ているとき」のほうが届きます。

そして、登録してもらうために必要なのは「登録してね」ではなく 次に何が来るか分かる約束です。 「毎晩、眠れない人へ1本」のように決まっていると、登録は約束の受け取りになります。

焦らなくて大丈夫です。1日1本を4週間続けたころに、やっと形が見えてきます。 伸びない日が続いても、それはあなたの言葉が届いていないという意味ではありません。

分かるところだけで大丈夫です。空欄のまま保存できます。 タイトルが同じ動画は、サムネイル・投稿日時・動画IDで見分けてください。 「Studio でこの動画の数字を見る」を押すと、その動画の画面がそのまま開きます。

取り込みの設定（YouTube APIキー）

キーを入れると、再生数だけでなくいいね・コメント数・尺・公開日時・登録者数まで自動で入ります。 入れないときは、チャンネルのページを読んで再生数と登録者数だけを取り込みます。 いいねとコメントは、そのときだけ手入力のままです。

取り方：Google Cloud コンソール でプロジェクトを作り、 「YouTube Data API v3」を有効にして、認証情報からAPIキーを作ります。課金の登録は要りません。 できたキーには「YouTube Data API v3 だけ」の制限を付けておくと安心です。
