間口と奥座敷

間口は、まだ知らない人に届くための動画です。ニッチに寄せすぎず、もっと多くの人が「これは分かる」と思える切り口にします。
奥座敷は、すでに見てくれている人を深いところへ連れていく動画です。 登録・相談ページ・長い話は、こちら側にあります。
間口ばかりだと通り過ぎられ、奥座敷ばかりだと新しい人が来ません。

映像化の比較基準

導入前のYouTube Studioで「過去28日間・ショート」を選び、終了日と「視聴を継続」を記録してください。下の保存ボタンで土台と一緒に保存します。

Studioのチャンネル集計値は参考値として別表示します。動画ごとの割合の中央値とは計算方法が異なります。導入後は開始日から28日間の投稿を比較対象にします。

入力中はこの端末に控えを残します。「保存する」で管理者専用のクラウドにも保存します。 保存済みの内容は、サイトの更新後や別の端末でも読み込めます。

次の1本を、AIとつくる

ClaudeCodex共通プロンプト

あなたの想いと動画の数字から、次の1本の制作指示をまとめます。 同じプロンプトを、Claude にも Codex にもそのまま貼り付けられます。

  1. 01数字と土台をまとめる
  2. 02プロンプトをコピー
  3. 03使いたいAIに渡す

生成するたびに画風（見た目・色・質感・文字の見せ方・カメラ・音色）を21種類から1つずつ変えます。前の回と同じ見た目にはしません。 題材と最初の一言（0〜3秒）は、伸びた回と同じく当事者の具体的な行動から作ります。テーマは再生の多いテーマから、一言の型は6つから順に選びます。 画風は形式名（例：画風1｜墨と和紙）で記録するので、伸びた回の画風を名前で見分けられます。 映像も音も、受け取ったAIがコード（Python と ffmpeg）で描いて書き出すので、動画生成サービスや実写の素材がなくても Claude・Codex だけで作れます。写真のような実写の質感は狙いません。 受け取るファイルは音入りの mp4 1本だけ。ほかに返ってくるのは、投稿に使う題名・説明文と、登録用の1行（文字だけ）です。 生成履歴はこのブラウザーに保存し、別の端末では登録済みの動画を参考にします。

今回の検証設計

画風は毎回まったく別のものにし、題材と最初の一言は伸びた回の作り方にそろえます。手応えのある画風を再検証する回だけ、変更を1つに絞ります。 有望な画風でも2本続けたら、別の画風に戻ります。 上の指示文にも、この設計がそのまま入ります。

これまでの形式の比較

過去の型と新しい型の最新記録を並べます。計測期間が異なる参考集計です。 次の型を選ぶ判定には、上の「今回の検証設計」を使います。

どこまで試したか

各型2本を目安に試します。直近3本の同じ投稿後日数の数字を比べ、複数回で手応えがあれば再検証します。本数だけで「確定」にはしません。

次に作る動画

何が効いているか

動画ごとの再生数を、チャンネルの中央値で割った「倍率」で比べています。1.0倍がふつうです。

伸びているチャンネルがしていること

視聴を継続した割合で冒頭の反応を、平均再生率で見続けた長さを確認し、1,000再生あたりの登録者数を合わせて見ます。 平均再生率は完走率ではありません。おすすめ配信の理由や途中離脱の場所は、これらの数字だけでは分かりません。

動画を作るときの型

できているものには印が付きます。数字が足りないものは灰色のままです。

星の海の場合の考え方

このチャンネルが届けたい相手は、いま眠れずにスマホを見ている人です。 そういう人は、明るく元気な動画を最後まで見ません。 最初の1秒に必要なのは、驚きではなく「これは自分のことだ」という手ざわりです。

ですので、伸ばし方も少しだけ普通と違います。 派手な効果音や煽りは合いません。かわりに効くのは、 静けさ・間・具体的な場面です。 「不安なとき」より「23時、天井を見ているとき」のほうが届きます。

そして、登録してもらうために必要なのは「登録してね」ではなく 次に何が来るか分かる約束です。 「毎晩、眠れない人へ1本」のように決まっていると、登録は約束の受け取りになります。

焦らなくて大丈夫です。1日1本を4週間続けたころに、やっと形が見えてきます。 伸びない日が続いても、それはあなたの言葉が届いていないという意味ではありません。

押すとその場で再生できます。テーマと掴みを入れるほど提案が鋭くなります。

再生数は「再生数を取り込む」で自動で入ります（自動と出ます）。 視聴を継続・いいね・コメント・平均視聴時間・登録者の増加は YouTube Studio の「アナリティクス → コンテンツ」から書き写してください。

視聴を継続（%）は、Studio の「視聴を継続」の割合です（フィードに出たうち、スワイプせずに見た人）。 「スワイプして次へ」は100%からこの値を引いて表示します。冒頭の反応を示す参考で、特定の1秒・3秒や離脱の原因は断定できません。投稿24時間後と4日後に、同じ集計範囲の数字を書き写してください。自動取得には未対応です。

分かるところだけで大丈夫です。空欄のまま保存できます。 日付が変わると入力欄はその日の記録になります。過去の数字は「前回」に表示され、分析にも残ります。 タイトルが同じ動画は、サムネイル・投稿日時・動画IDで見分けてください。 「Studio でこの動画の数字を見る」を押すと、その動画の画面がそのまま開きます。

取り込みの設定（YouTube APIキー）

キーを入れると、再生数だけでなくいいね・コメント数・尺・公開日時・登録者数まで自動で入ります。 入れないときは、チャンネルのページを読んで再生数と登録者数だけを取り込みます。 いいねとコメントは、そのときだけ手入力のままです。

取り方：Google Cloud コンソール でプロジェクトを作り、 「YouTube Data API v3」を有効にして、認証情報からAPIキーを作ります。課金の登録は要りません。 できたキーには「YouTube Data API v3 だけ」の制限を付けておくと安心です。
